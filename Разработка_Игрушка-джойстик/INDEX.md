# Индекс проекта «Разработка_Игрушка-джойстик»

> В этот комплект вошёл только конвейер новостей. Разделы «ТЗ», «Примеры», план развития и бизнес-документы ниже описывают рабочий проект и здесь отсутствуют.

- `README.md` — конвейер новостей: что делает, подготовка (.env, доступы), команды запуска, пользовательский сценарий, выходные файлы, частые ошибки

## ТЗ
- `ТЗ_концепция.md` — концепция: фигурки девочки и медведей по сказке «Три медведя» (3D-печать → мелкосерийная форма) с датчиками положения и кнопками как джойстик для сценарной игры на экране.
- `ТЗ_сайт/` — материалы для сайта: скриншот foxford.ru (без md-описания) и иллюстрации к 5 сказкам (59 jpg): по 2 картинки на каждого персонажа и по 2 сцены. В каждой подпапке есть `*_иллюстрации_описание.md`: что изображено, источник, художник, статус прав (образец или общественное достояние).
  - `Колобок/` — 16 картинок (современная книжка + А. Медведев, 1913, общественное достояние)
  - `Три_медведя/` — 10 картинок (предположительно Ю. Васнецов, права действуют, только образец)
  - `Лиса_и_заяц/` — 10 картинок (нет Быка, нет второй картинки Собаки и Медведя)
  - `Гуси-лебеди/` — 15 картинок (нет второй картинки Бабы-яги)
  - `Волк_и_семеро_козлят/` — 8 картинок (О. Херфурт, Г. Фогель, общественное достояние, немецкий антураж)

## Документы
- `Новости/` — справки по новостям об ИИ-игрушках с проверкой фактов (черновик готовит субагент `news-ai-toys-search`, проверяет и выносит вердикт `news-ai-toys-validator`, по справкам с вердиктом «годится» пишет посты `news-ai-toys-content-writer`; все — в `D:\myai\.claude\agents\`):
  - `ИИ-игрушки_новость_mallow-без-экрана_2026-10-15.md` — Mallow (Франция): колонка без экрана для детей 4–10 лет, игра голосом с ИИ-персонажами; проверка 21 факта, риски по голосу и приватности
  - `ИИ-игрушки_новость_калифорния-мораторий-ии-игрушек_2026-10-16.md` — закон Калифорнии SB 867: запрет ИИ-игрушек-«компаньонов» для детей до 16 лет на 2027–2030; проверка 13 фактов, расхождения по возрасту/голосованию, штрафы [уточнить]
  - `ИИ-игрушки_новость_утечка-робот-eiliko_2026-10-17.md` — роботы Eilik/Eiliko (Energize Lab): разговоры детей на открытых серверах в Китае, удалённое перепрограммирование, 9 CVE; проверка 14 фактов, расхождения в цифрах
  - `ИИ-игрушки_кандидаты_реестр.md` — общий реестр всех кандидатов новостей (выбрана / резерв / отказ), пополняется после каждого поиска
- `Конвейер-новостей_инструкция-тестирования_2026-10-17.md` — инструкция для агента-тестировщика: 8 шагов цепочки (поиск → проверка → посты → картинка → сайт → выкладка), ожидаемые результаты, известные ограничения (VPN и хостинг)
- `Скрипты/` — скрипты конвейера новостей:
  - `deploy_site.py` — выкладка `Результат/Сайт/` на хостинг Рег.ру (Host-0) по SFTP: показывает новые/изменённые файлы, выкладывает после подтверждения, на сервере ничего не удаляет, пишет `журнал_выкладки.csv`
  - `gigachat_img.py` — картинка к посту через GigaChat API (встроенный Kandinsky): по полю `image` из JSON поста сохраняет `.jpg` рядом с JSON, существующие не перезаписывает; `--check` — проверка ключа без расхода квоты; пишет `журнал_картинок.csv`
  - `certs/russian_trusted_root_ca.pem` — корневой сертификат НУЦ Минцифры для HTTPS к GigaChat (SHA-256 D2:6D:2D:02…CF:31, действует до 2032)
  - `build_dashboard.py` — собирает пульт `Результат/Пульт-конвейера.html` из справок, постов, реестра, news.html и журналов (`--open` — открыть в браузере)
  - `post_check.py` — проверка JSON поста: точные длины (Telegram ≤950 с хэштегами, MAX ≤1200, ВК ≤1500), хэштеги, метки [уточнить]; код 1 — вернуть пост на доработку
  - `.env.example` — образец файла доступов (хостинг, ключ GigaChat); сам `.env` в git не попадает
- `План-развития/` — исходники PDF-плана на 30 дней: `План-развития_30-дней.html` и скриншоты `скрин_01…04_*.png` (страница «Новости» до/после, новый скилл, прогон цепочки)

## Результат
- `Пульт-конвейера.html` — интерфейс конвейера (живой файл, пересобирается `build_dashboard.py`): счётчики, команды запуска, лента новостей со статусами, тексты постов с кнопкой «Копировать», справки без постов, резерв, журналы
- `Конвейер-новостей_описание-проекта_2026-10-17.md` — описание итогового проекта «Конвейер новостей об ИИ-игрушках»: проблема, пользователь, 6 шагов (поиск → валидация → текст → картинка через GigaChat/Kandinsky → вёрстка → публикация по SFTP), формат результата, MVP и планы, технологии.
- `Игрушка-джойстик_план-развития-30-дней_2026-10-16.pdf` — личный план развития на 30 дней (вектор «автоматизация контента»: конвейер новостей об ИИ-игрушках), маршрут, план по неделям, первое действие (скилл «пост → сайт») со скриншотами. Есть md-версия (`.md`, скриншоты описаны текстом).
- `Игрушка-джойстик_анализ-рынка_2026-09-24.md` — маркетинговое исследование: права на сказку «Три медведя» (общественное достояние, не путать с мультсериалом «Маша и Медведь»), аналоги (Skylanders/Amiibo/Disney Infinity, WOWCube, Lego Smart Brick, myStorymaker/ToyPal), сравнение технологий (NFC/RFID vs IMU vs кнопки), рекомендация по прототипу (ESP32+IMU+BLE).
- `Игрушка-джойстик_подбор-сказок_2026-10-08.md` — сказки без лицензии (Три медведя, Колобок, Лиса и заяц, Гуси-лебеди, Волк и семеро козлят), Винни-Пух свободен с 2027 — пока не включён, проверка товарных знаков (на «Три медведя» есть знак № 244370 в кл. 28, по остальным знаков не найдено, проверка предварительная), открытые вопросы, исключённые варианты, правовая база с источниками.
- `Интерактивная-сказка_PRD_2026-10-08.md` — PRD лендинга: цель и ЦА, структура секций, стек, дизайн (референс foxford.ru), файловая структура, тексты-заглушки, что сделать перед запуском (права на картинки, ПДн, товарный знак).
- `Сайт/` — драфт лендинга «Интерактивная сказка» (HTML/CSS/JS без сборки, открыть `index.html`): hero с веером карточек, которые наклоняются за курсором или телефоном, мини-демо развилки, польза, как это работает, каталог из 5 сказок, доверие (заглушки), форма заявки, футер.
  - `Сайт/news.html` — страница «Новости об ИИ-игрушках»: 9 новостей (добавляются скиллом `news-ai-toys-site`) из `Посты/` (текст ВК-версии без хештегов и вопроса к читателям, ссылка на источник), новые сверху; у всех карточек картинки — копии из `Посты/` в `assets/img/news/`. Ссылка «Новости» в меню и футере главной.
