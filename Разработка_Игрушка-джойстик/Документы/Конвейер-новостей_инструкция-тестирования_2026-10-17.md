## Проверка доступа на хостинг (перед шагами 7–8)

Хостинг Рег.ру, тариф Host-0, доступ по SFTP (порт 22). Доступы — в `Документы/Скрипты/.env` (поля `SFTP_HOST` = IP сервера, `SFTP_PORT`, `SFTP_USER`, `SFTP_PASSWORD`, `SFTP_REMOTE_DIR`). Сам `.env` не открывать — скрипт читает его сам.

Выполнять по порядку, на первом сбое — остановиться и записать результат:

| # | Проверка | Команда (PowerShell) | Норма |
|---|---|---|---|
| Х1 | Файл доступов на месте | `Test-Path "D:\myai\Разработка_Игрушка-джойстик\Документы\Скрипты\.env"` | `True` (если есть только `.env.txt` — Блокнот дописал расширение, переименовать в `.env`) |
| Х2 | VPN выключен | `Get-NetAdapter \| Where-Object Status -eq 'Up' \| Select-Object Name` | Нет адаптера `hidemyVPN` (или Иван подтвердил, что в VPN сделано исключение) |
| Х3 | Интернет вне браузера работает | `curl.exe -I https://ya.ru` | Строка `HTTP/1.1 200` или `301` |
| Х4 | Подключение к серверу | `python "D:\myai\Разработка_Игрушка-джойстик\Документы\Скрипты\deploy_site.py" --check` | Первый раз: «Сервер … ещё не известен. Отпечаток ключа: …». Показать отпечаток Ивану |
| Х5 | Запомнить сервер | то же с `--trust-new-host` — **только после подтверждения Ивана** | «Ключ сервера сохранён в known_hosts», затем «Подключено: …» |
| Х6 | Папка сайта | повторить `--check` | «Подключено …», «Папка сайта …: N объектов» и список файлов |
| Х7 | Что будет выложено | `deploy_site.py` без параметров | «Без изменений: X. К выкладке: Y» и список; ничего не выложено |

Ошибки и что они значат:

| Сообщение | Причина | Что делать |
|---|---|---|
| `Нет файла …\.env` | Файла нет или он `.env.txt` | Переименовать / создать из `.env.example` |
| `getaddrinfo failed` | В `SFTP_HOST` не адрес сервера | Иван вписывает IP сервера из вкладки «Доступы» |
| `Error reading SSH protocol banner` | Соединение без ответа: VPN, антивирус (Kaspersky), блок со стороны Рег.ру | Повторить Х2–Х3. Если Х3 в норме, а ошибка осталась — Иван проверяет вручную `ssh -o ConnectTimeout=15 <логин>@<IP>` и при молчании пишет в поддержку Рег.ру |
| `Authentication failed` | Неверный логин/пароль | **Не повторять больше одного раза**: после нескольких неудачных попыток Рег.ру блокирует SSH на ~2 часа. Иван сверяет пароль SSH во вкладке «Доступы» |
| `На сервере нет папки …` | Неверный `SFTP_REMOTE_DIR` | Иван смотрит путь к сайту в файловом менеджере ispmanager (обычно `www/<домен>`) |
| `Сервер … ещё не известен` при уже сохранённом ключе / ошибка о смене ключа | Ключ сервера изменился | Не принимать молча — сообщить Ивану, сверить с поддержкой Рег.ру |

## Известные ограничения (на 17.10.2026)
- Шаг 7–8: с этого компьютера подключение к хостингу зависает (`Error reading SSH protocol banner`). Вероятная причина — включённый hidemyVPN (трафик вне браузера не проходит, `curl -I https://ya.ru` тоже падает). Перед шагом 7 отключить VPN и проверить `curl.exe -I https://ya.ru`. При первом подключении скрипт покажет отпечаток ключа сервера — запомнить его с `--trust-new-host` только после подтверждения Ивана.
- Субагент `news-ai-toys-validator` новый — доступен после перезапуска Claude Code.
- Оркестратор — скилл `news-ai-toys-pipeline` («сделай новость про ИИ-игрушки»): проводит по шагам 1–8 с двумя остановками на подтверждение Ивана. Сначала тестировать шаги по отдельности, затем один сквозной прогон через оркестратор.
- Длины постов: `python Документы/Скрипты/post_check.py <JSON>` — Telegram ≤950 символов (посты Калифорнии и Eiliko сделаны до лимита и его превышают — это ожидаемо).
