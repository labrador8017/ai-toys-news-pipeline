# Пост (JSON) → новость на странице «Новости» сайта

Цепочка: `news-ai-toys-search` (черновик справки) → `news-ai-toys-validator` (проверка, вердикт) → `news-ai-toys-content-writer` / скилл `news-ai-toys-post` (JSON) → **этот скилл** (сайт).

Пути (от `D:\myai\Разработка_Игрушка-джойстик\`):
- вход: `Результат/Посты/*.json` (+ картинка рядом с тем же именем, `.jfif`/`.jpg`/`.png`, если Иван её сгенерировал);
- выход: `Результат/Сайт/news.html`, картинки — `Результат/Сайт/assets/img/news/`.

## Вход

Иван называет пост (имя файла, тему) или говорит «последний». Если не ясно какой — найди JSON в `Результат/Посты/`, которых ещё нет на странице (сравни `source.url` с `href` ссылок `post__src` в news.html), и предложи список.

Если новость с тем же `source.url` уже есть на странице — не дублируй, сообщи Ивану.

## Порядок работы

1. Прочитай JSON целиком и `news.html` (как минимум 2–3 существующие карточки — это эталон стиля).
2. Возьми за основу текст `platforms.vk.content` (самый полный). Убери:
   - хештеги и строку с ними;
   - вопрос к читателям в конце («А вы…?», «Пишите в комментариях»);
   - эмодзи и markdown (`**`, `__`);
   - строку со ссылкой на источник (она пойдёт в `post__src`).
3. Собери карточку:
   - `id` — короткий латинский slug по теме (`mallow`, `pirg-kumma`), уникальный на странице;
   - `<time datetime="ГГГГ-ММ-ДД">` = `source.published_at`, подпись «30 сентября 2026». Если известен только месяц — `datetime="ГГГГ-ММ"`, подпись «Ноябрь 2025»;
   - `post__tag` — одно слово по смыслу; переиспользуй существующие теги, если подходят: Безопасность, Новинка, Стандарты, Исследование, Тесты, Чтение, Обзор;
   - `post__title` — заголовок-факт до ~100 знаков (первая строка поста, если она подходит; иначе переформулируй без кликбейта);
   - абзацы `<p>`; перечисления — `<p>Вводная:</p><ul><li>…;</li></ul>`;
   - совет родителям — `<p class="post__tip"><b>Наш совет:</b> …</p>` (если в тексте позиция редакции — `<b>Мы согласны:</b>` / `<b>Наше мнение:</b>`);
   - `<a class="post__src" href="{source.url}" target="_blank" rel="noopener">Источник: {издание}</a>` — издание коротко, по-русски, если есть устоявшееся название.
4. Типографика как на странице: неразрывный пробел `&nbsp;` после коротких предлогов/союзов (в, с, к, о, у, и, а, но, на, по, не, до, от, за, из, для, что, ли, же) и между числом и единицей (`5&nbsp;лет`, `119,99&nbsp;€`); дефис в «ИИ-игрушках» в заголовке h1 не трогать.
5. Картинка: если рядом с JSON лежит файл картинки с тем же базовым именем — скопируй его в `Сайт/assets/img/news/{slug}.jpg` (оригинал не трогать), карточке добавь класс `post--pic` и первой строкой внутри `<article>`:
   `<img class="post__pic" src="assets/img/news/{slug}.jpg" alt="{краткое описание по image.prompt}" loading="lazy">`.
   Нет картинки — обычная карточка без `post--pic`.
6. Вставь `<article class="post reveal" id="…">` в ленту `<section class="sheet news">` строго по дате, новые сверху. Отступы — как у соседних карточек (4 пробела у `<article>`), пустая строка между карточками. Ничего другого на странице не меняй.
7. Факты: не добавляй ничего, чего нет в JSON. Пункты из `unverified` на сайт как факт не выносить — только как «по словам компании» (как в посте) или не упоминать. Метки `[уточнить]` на сайт не попадают: если такая метка есть в тексте поста — остановись и спроси Ивана.
8. Проверка: страница открывается (если доступен Playwright — подними `python -m http.server` в `Результат/Сайт/` и посмотри новую карточку), число `<article>` выросло на 1, порядок дат не нарушен, ссылка источника рабочая (совпадает с `source.url`).
9. Обнови `INDEX.md` проекта: в строке про `Сайт/news.html` — новое число новостей; в разделе `Посты/` — новый JSON, если его там нет.
10. Коммит по правилам CLAUDE.md: «Игрушка-джойстик: новость <тема> на сайте».

## Чего не делать

- Не выкладывать сайт на хостинг и не публиковать в соцсети — только локальные файлы.
- Не менять оформление страницы, CSS и другие карточки (кроме явной просьбы Ивана).
- Не удалять и не перезаписывать JSON и картинки в `Посты/`.
