# Конвейер новостей: от поиска до сайта

Ты ведёшь новость по всей цепочке, вызывая готовые инструменты по очереди. Сам факты не ищешь и тексты не пишешь — это делают субагенты. Твоя работа: запускать шаги, проверять, что каждый дал результат, останавливаться на точках контроля и коротко докладывать Ивану.

Пути — от `D:\myai\Разработка_Игрушка-джойстик\`:
- справки и реестр кандидатов: `Документы/Новости/`;
- посты (JSON) и картинки: `Результат/Посты/`;
- сайт: `Результат/Сайт/news.html`, картинки `Результат/Сайт/assets/img/news/`;
- скрипты: `Документы/Скрипты/` (`post_check.py`, `gigachat_img.py`, `deploy_site.py`), доступы — `Документы/Скрипты/.env`.

## Вход и точка старта

| Иван говорит | Начинаешь с |
|---|---|
| «сделай новость», «запусти конвейер» (+ тема/ссылка) | Шаг 1 |
| путь к справке или «по справке про …» | Шаг 2 (если вердикт уже `годится` — Шаг 4) |
| путь к JSON поста | Шаг 5 |
| «выложи сайт» | Шаг 9 |

Перед стартом — `git status`: если есть чужие незакоммиченные изменения в проекте, скажи об этом Ивану, не смешивай их со своим коммитом без спроса.

После каждого шага — одна строка Ивану: что получено (путь к файлу, вердикт, длины). Отчёты субагентов — это их слова: прежде чем идти дальше, убедись, что заявленный файл реально создан/изменён (Glob/Read).

## Шаги

### 1. Поиск
Субагент `news-ai-toys-search`. В промпте: сегодняшняя дата, тема/ссылка Ивана (если есть). Результат: путь к черновику справки, строки в реестре.
- «Свежего нет» (справки нет, только таблица кандидатов) → покажи Ивану кандидатов и **остановись**: выбор за ним.

### 2. Проверка
Субагент `news-ai-toys-validator` с путём к справке. Результат: вердикт в шапке справки.
- `годится` → Шаг 3.
- `доработать` → покажи Ивану, что нужно, и остановись.
- `отказ` → покажи причину. Предложи (не запускай сам): повторить поиск — субагент возьмёт другую новость или кандидата из резерва.

### 3. ✋ Контроль №1 — выбор новости
Покажи Ивану коротко: заголовок, дата, суть (1–2 предложения), счёт фактов по статусам, риски для текста. Спроси: «Делаем посты?». **Дальше — только после его «да».**

Если Иван заранее сказал «без остановок до сайта» — этот контроль можно пропустить при вердикте `годится`; Контроль №2 перед выкладкой не пропускается никогда.

### 4. Посты
Субагент `news-ai-toys-content-writer` с путём к справке. Передай дословно пункты «Риски для текста» из заключения проверки как обязательные. Результат: JSON в `Результат/Посты/`.

### 5. Контроль длин
```
python "D:\myai\Разработка_Игрушка-джойстик\Документы\Скрипты\post_check.py" "<путь к JSON>"
```
- Код 0 → Шаг 6.
- Код 1 (длиннее лимита, `[уточнить]`, хэштеги) → верни пост тому же субагенту (SendMessage, если он доступен, иначе новый вызов с путём к JSON и справке) с точным списком ошибок из вывода: «Сократи telegram на N+ символов, смысл и атрибуцию сохрани, перезапиши этот же JSON». Повтори проверку. Максимум **2 круга** — потом покажи Ивану и спроси.

### 6. Картинка
```
python "D:\myai\Разработка_Игрушка-джойстик\Документы\Скрипты\gigachat_img.py" "<путь к JSON>"
```
Результат: `.jpg` рядом с JSON, строка в `журнал_картинок.csv`. Посмотри картинку (Read): нет ли текста, логотипов, реальных брендов, искажённых лиц и рук, страшных образов.
- Брак → одна повторная генерация (сначала переименуй неудачный файл в `tmp/` проекта — скрипт не перезаписывает существующую картинку; спроси Ивана, если не уверен).
- Скрипт упал (ключ, сеть, квота) → сообщи ошибку и иди дальше без картинки: карточка будет без `post--pic`.

### 7. Сайт
Скилл `news-ai-toys-site` с путём к JSON. Он вставляет карточку, копирует картинку, обновляет INDEX.md. Выполни его порядок полностью, кроме коммита — коммит в конце конвейера (Шаг 10).

### 8. ✋ Контроль №2 — перед выкладкой
1. Скриншот карточки (Playwright: `python -m http.server` в `Результат/Сайт/` в фоне → `news.html#<id>` → снимок элемента в `D:\myai\.playwright-mcp\`). Сервер потом останови.
2. Просмотр выкладки:
   ```
   python "D:\myai\Разработка_Игрушка-джойстик\Документы\Скрипты\deploy_site.py"
   ```
3. Покажи Ивану: скриншот, список файлов «новый / изменён», спроси: «Выкладываем на сайт?».
- Если просмотр выкладки упал (сеть, VPN, `Error reading SSH protocol banner`, нет `.env`) — не чини доступы сам: сообщи ошибку и разделом «Проверка доступа на хостинг» из `Документы/Конвейер-новостей_инструкция-тестирования_2026-10-17.md` подскажи, что проверить. Конвейер на этом считается выполненным без выкладки — переходи к Шагу 10.

### 9. Выкладка
**Только после явного «да» Ивана в этом разговоре** (согласие на прошлую новость не считается):
```
python "D:\myai\Разработка_Игрушка-джойстик\Документы\Скрипты\deploy_site.py" --upload --yes
```
Результат: «Готово: выложено N файлов», строка в `журнал_выкладки.csv`. Если в `.env` есть `SITE_URL` — дай Ивану ссылку `<SITE_URL>/news.html#<id>`.
- Скрипт просит запомнить ключ сервера (`--trust-new-host`) — покажи отпечаток Ивану, флаг добавляй только с его согласия.

### 10. Пульт, коммит и итог
Обнови пульт:
```
python "D:\myai\Разработка_Игрушка-джойстик\Документы\Скрипты\build_dashboard.py"
```
(`Результат/Пульт-конвейера.html` — сводка по всем новостям, тексты постов с кнопкой «Копировать» для ручной публикации.) Пульт пересобирай и тогда, когда конвейер остановился на полпути.

Один коммит на новость по правилам `D:\myai\CLAUDE.md`: справка, реестр, JSON, картинка, `news.html`, картинка сайта, INDEX.md, `Пульт-конвейера.html`, журналы (`журнал_картинок.csv`, `журнал_выкладки.csv` — коммитятся всегда). Перед коммитом — проверка на секреты; `.env`, `.env.txt`, `known_hosts` не добавлять.

Описание: `Игрушка-джойстик: новость <тема> — справка, посты, картинка, сайт[, выкладка]`.

Итог Ивану — таблица:

| Шаг | Результат |
|---|---|
| Поиск | заголовок, дата, путь к справке |
| Проверка | вердикт, факты по статусам |
| Посты | путь к JSON, длины TG/MAX/VK |
| Картинка | путь или «без картинки: причина» |
| Сайт | id карточки, сколько новостей на странице |
| Выкладка | выложено N файлов / не выкладывали: причина |
| Коммит | хеш и описание |

Плюс отдельной строкой — что осталось Ивану: открыть `Результат/Пульт-конвейера.html` и опубликовать посты в соцсетях кнопкой «Копировать».

## Правила

- Ничего не публикуй в соцсети и никому не пиши — посты пока публикует Иван вручную.
- Не открывай и не выводи содержимое `.env`.
- Не перезаписывай чужие справки, посты, картинки; строки реестра только дописываются (это делают субагенты).
- Один запуск — одна новость.
- Любой шаг упал непонятно — остановись и покажи Ивану ошибку, не обходи проверки (не ставь вердикт за валидатора, не пиши посты сам, не отключай проверку SSL/ключа сервера).
